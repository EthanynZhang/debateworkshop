# debateworkshop

访问 <https://ethanynzhang.github.io/debateworkshop/> 后，会在当前标签页立即打开指定的 Google Drive 下载文件夹。

网站使用 `location.replace()` 跳转，并提供无需 JavaScript 的 HTML 自动跳转和手动链接。

## 修改跳转地址

编辑 `index.html` 中的三个网址（JavaScript、meta refresh、备用链接），保持一致，然后提交到 `main`。GitHub Pages 发布来源为 `main` 分支根目录。

文件由 Google Drive 托管，访问权限取决于文件夹和文件的共享设置。此仓库只包含跳转页，不包含安装包或凭据。
